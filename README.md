## 🫀 Featured Engineering Project: Waterproof Heart Rate Monitoring System

An end-to-end biomedical IoT wearable and cloud telemetry dashboard engineered for continuous aquatic and sweat-resistant cardiac pulse monitoring.

### 🌟 Key Highlights & Engineering Architecture:
- **Low-Level C/C++ Firmware & DSP**: Executes real-time PPG peak-detection and a 2nd-order Butterworth bandpass filter (0.5Hz – 4.0Hz) to suppress motion artifacts caused by hydrodynamic resistance during swimming.
- **Hermetically Sealed IP68 Enclosure**: Designed with medical-grade silicone O-rings and ultrasonic welding, safe up to 50 meters water submersion.
- **Sub-85ms Telemetry**: Dual-radio transmission utilizing standard Bluetooth Low Energy (BLE 0x180D Heart Rate Profile) and Wi-Fi MQTT WebSockets.
- **Interactive Live Web Dashboard**: Real-time simulated ECG/PPG waveform graph renderer, activity mode simulator (*Resting*, *Swimming*, *Sprint*), bradycardia/tachycardia threshold alarms, depth gauge, and battery status.

### 🛠️ Tech Stack:
`C / C++` • `Embedded ESP32` • `PPG Sensors` • `Digital Signal Processing (DSP)` • `BLE / MQTT` • `React` • `Tailwind CSS` • `TypeScript` • `Motion`

## 🚀 Getting Started Locally

To run this portfolio locally on your machine:

```bash
# 1. Clone this repository
git clone https://github.com/salabhpandey12345-alt/my_portfolio.git

# 2. Navigate to project directory
cd my_portfolio

# 3. Install dependencies
npm install

# 4. Start local development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) (or Vite port) in your browser.
